# Phase 5 M5 — Private Beta

## Goal

Use AI Career OS for real personal job searching before considering any public release.

---

# Beta Scope

Initially:

- one user
- real jobs
- real applications
- real email account
- controlled application execution

---

# Test Period

Run the system through a meaningful real-world sample.

Target:

- 50–100 qualified job opportunities
- multiple applications
- multiple recruiter interactions where available
- interview workflow when available

---

# Measure

Track:

## Discovery

- jobs discovered
- relevant jobs

## Matching

- high-quality matches
- false positives

## Applications

- prepared
- approved
- submitted
- failed

## Communication

- recruiter messages
- responses
- follow-ups

## Interviews

- detected
- preparation generated
- mock interviews

---

# Reliability

Record every failure.

Classify:

- provider failure
- AI failure
- application failure
- email failure
- matching failure
- UI failure
- infrastructure failure

---

# Human Review

During beta, keep high-risk automation conservative.

Default:

```text
AUTO_APPLY = OFF
AUTO_SEND = OFF
